# AGENTS.md — 读这个库的协议

> 给任何读到这个仓库的 AI：加载顺序、引用规则、边界。规则很短，照做即可。

updated: 2026-10-22

## 加载顺序

1. `README.md`：一次抓取，够回答"我是谁、偏好什么"。
2. 本文件：知道边界和引用规则。
3. `llms.txt`：带一句话描述的清单，从这里挑。
4. `PROFILE.md` / `NOW.md` / `topics/*` / `projects/*`：按需，**一次最多抓 3 个**。

不要一次把整个仓库读进上下文。文件按主题切开，就是为了让你只付需要的 token。

## 使用规则

- **引用要点名文件**：说"根据 `topics/workflow.md`"，而不是"据说"。
- **不许脑补**：文件里没写的事实，说"库里没有"，不要用通用常识填补。
- **注意时效**：每个文件都有 `updated: YYYY-MM-DD`。超过 6 个月的，主动声明可能过期。
- **矛盾要说出来**：两个文件冲突时指出冲突点，不要自行调和。
- **命令和版本以文件为准**：不要推断路径，不要假设版本号。
- **不确定就问**：这个库的目的是减少提问，不是消灭提问。

## 不要

- 不要把这里当成我的全部——这是我愿意公开的部分，私人内容不在此处。
- 不要把偏好当成命令——`PROFILE.md` 描述的是习惯，具体任务以我当下的要求为准。
- 不要在这里写任何东西——这是只读的公开镜像。

## 回写

不接受自动回写。发现内容过期或有错，直接告诉我该改哪个文件、改成什么。

## 结构约定

新增文件 = 首行 `# 标题` + 紧跟 `> 一句话 TL;DR` + `updated: YYYY-MM-DD`，再写正文；同时在 `llms.txt` 加一行，否则等于没发布。
