## 单项目模板

新建 `projects/<名字>.md`，写：目标 / 现状 / 技术栈 / 关键决定 / 坑 / 链接。

然后在两处登记，否则等于没发布：

1. 本页表格加一行；
2. `llms.txt` 的「项目」一节加一行。
