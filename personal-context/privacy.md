# privacy — 公开边界

> 这个仓库是公开的。这里写清楚哪些信息我故意公开、哪些永远不会出现。

updated: 2026-10-22

## 故意公开的

- 我对 AI 的沟通与交付偏好（为了少解释几遍）。
- 这台机器的粗略环境和工具版本（为了让人给对命令）。
- 我写过的公开项目、踩过的公开坑。

## 永远不在这里的

- 密码、API key、token、私钥、OAuth 凭证。
- 手机号、身份证号、真实住址、生日、家庭成员与他人隐私。
- 邮箱与社交账号的完整值（需要联系方式的场景单独沟通）。
- 客户名、未公开项目名、任何第三方隐私。
- 私有记忆库 `ai-memory` 的内容。

## 提交前自检

推之前，在仓库根目录跑（PowerShell）：

```powershell
git diff --cached -U0 | Select-String -Pattern '@qq\.com|1[3-9]\d{9}|\bsk-|\bghp_|\bAKIA|\d{17}[\dXx]|password|token'
```

有命中就停下来，先判断是不是误报。

## 已公开的收不回来

一旦 push，搜索引擎和模型都可能缓存。**推送是不可逆的**，比 commit 更该谨慎。
